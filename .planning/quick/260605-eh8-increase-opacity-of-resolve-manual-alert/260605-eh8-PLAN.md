<objective>
The modal used for resolving an alert in the React SPA — the "Terminate / resolved"
dialog (`TerminateDialog`) — is too transparent. Its surface is `.glass-card`, whose
dark-mode background token is only `rgb(255 255 255 / 0.07)` over a faint gradient, so
the page behind bleeds through and ruins readability.

The same `.glass-card` surface is shared by the sibling `ExtendDialog` and the
manual-entry `ConfirmationModal`, AND by many non-modal full-page panels site-wide. So
the global token must NOT change (that would over-darken the whole UI). Instead, add a
narrow `glass-dialog` surface modifier and apply it only to the three modal surfaces.

Purpose: Restore legibility of modal dialog content while preserving the glassmorphism
design language and leaving all non-modal panels untouched.

Output: A new `glass-dialog` @utility in index.css plus the modifier applied to the
three modal surfaces (TerminateDialog, ExtendDialog, ConfirmationModal).
</objective>

  <action>
Add a new `@utility glass-dialog` rule immediately AFTER the existing `@utility glass-card`
block (do NOT modify glass-card, glass-navbar, or glass-item — non-modal panels depend on
them). This modifier is applied on top of glass-card on modal surfaces, so it only needs to
override the background and tighten blur:

- Set `background` to a near-solid dark slate surface that keeps a hint of glass: a faint
  light gradient overlay over an opaque slate base. Use `rgb(15 23 42 / 0.92)` (slate-900 at
  ~92%) as the base so content is clearly legible while still reading as glassmorphism. Keep a
  subtle top-light gradient: `linear-gradient(135deg, rgb(255 255 255 / 0.07), rgb(255 255 255 / 0.02) 60%)`
  layered over the slate base.
- Strengthen blur: `backdrop-filter: blur(28px) saturate(140%)` and the matching
  `-webkit-backdrop-filter`.
- Do NOT set padding, border, border-radius, or box-shadow — those are inherited from
  glass-card (the modifier is always applied alongside glass-card). Adding them would be
  redundant.

This satisfies the EH8-OPACITY requirement: modal surface goes from ~7% to ~92% opacity.
Keep the file under the project's 300–400 line refactor threshold (it is well under).
